# Лабораторная работа №1: Основы ООП (Tic-Tac-Toe)

## Описание
Реализация игры «Крестики-нолики» на C++ с использованием принципов ООП. 
Поддерживается произвольный размер поля и настраиваемая длина линии для победы.

## Реализованные требования
- Инкапсуляция (приватные поля, публичные методы).
- Разделение интерфейса (.h) и реализации (.cpp).
- Конструктор копирования и оператор присваивания.
- Операторы сравнения (==, !=) и потоки ввода/вывода (<<, >>).
- Юнит-тесты (GoogleTest), покрывающие основную логику.
- Консольный интерфейс (CLI), отделённый от класса игры.

## Структура проекта
- include/TicTacToe.h — заголовочный файл класса.
- src/TicTacToe.cpp — реализация логики игры.
- src/main.cpp — консольный интерфейс.
- tests/test_tictactoe.cpp — юнит-тесты.

## Сборка и запуск
```bash
mkdir build
cd build
cmake -G "MinGW Makefiles" ..
cmake --build .
```

### Запуск игры:
```bash
./lab1_app.exe
```

### Запуск тестов:
```bash
ctest --output-on-failure
```
